If dragging doesn't work

  1. Hit Copy the code instead.
  2. Right-click your bookmarks bar → Add page (Chrome) or Add bookmark (Firefox).
  3. Name it SBC Autopilot and paste the code into the URL field.

Bookmarks bar hidden? Ctrl/Cmd + Shift + B.

Or run it as a userscript

If you already use Tampermonkey or Violentmonkey, the userscript above is the sturdier install — it loads itself on the web app every time, so there's no bookmark to click and no length limit to worry about.

Using it

  1. Open the FUT Web App and log in as normal.
  2. Click the bookmark. A panel appears in the top right — drag it anywhere.
  3. Hit Start harvesting, then go to your club and scroll through your players. The web app only draws what's on screen, so it can only read what you've scrolled past. The counter climbs as you go.
  4. Open the SBC you want to do and hit Read requirements. Check what it picked up — the box is editable, so fix anything it got wrong.
  5. Pick the formation and hit Solve. You get the eleven players, which slot each one goes in, and a pass/fail line for every requirement.
  6. Build it yourself in the app.
Also useful: Copy club

Dumps everything harvested as a table you can paste straight into the solver page — handy for planning several SBCs without re-scrolling your club, or for adding real market prices by hand.

What it does and doesn't do

It does

Read the page you're already looking at, do the maths, and show you the answer. Everything runs in your browser and stays there.

It doesn't

Click, drag, submit, buy, sell, or automate anything. It makes no network calls — nothing is uploaded, and no third-party price site is contacted.

EA's terms ban third-party FUT tools

That applies to this one. Using it is at your own risk, and the risk lands on your account. It was built read-only partly for that reason: it never acts for you, so there are no automated actions to look like a bot. Your judgement, your call.

Two honest limitations

Prices are estimated from rating. The club list shows no market values and this tool won't call out to a price site, so "cost" is a rating-based proxy for how painful a player is to spend — not coins. Paste your club into the solver page if you want to work with real prices.

Reading the page is best-effort. It finds players by shape — a rating, a position, a crest — rather than by EA's class names, so it survives redesigns better than most. But it has not been verified against the live web app, which needs an EA login. If the panel says chemistry data is patchy, believe it, and check the squad in game before you submit.
